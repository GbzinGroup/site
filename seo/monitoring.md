# Monitoramento SEO - Gbzin Group

## Ferramentas obrigatorias

### Google Search Console
URL: https://search.google.com/search-console
- Adicionar propriedade gbzin.com.br
- Verificar via DNS ou HTML
- Enviar sitemap.xml
- Verificar erros de indexacao
- Ver posicao das palavras-chave
- Analisar CTR

### Google Analytics 4
URL: https://analytics.google.com
- Criar propriedade
- Adicionar gtag.js
- Configurar eventos
- Configurar conversoes

### Bing Webmaster Tools
URL: https://www.bing.com/webmasters
- Importar do Google Search Console
- Enviar sitemap

## Metricas para acompanhar

### Semanalmente
- [ ] Impressoes no Google
- [ ] Cliques
- [ ] CTR medio
- [ ] Posicao media
- [ ] Trafego organico

### Mensalmente
- [ ] Palavras-chave ranqueadas (top 10, 20, 50, 100)
- [ ] Backlinks novos
- [ ] Core Web Vitals
- [ ] Paginas indexadas
- [ ] Erros de rastreamento

### Trimestralmente
- [ ] Revisao de conteudo
- [ ] Analise de concorrentes
- [ ] Atualizacao de palavras-chave
- [ ] Auditoria tecnica completa

## Sinais de alerta
- ⚠️ Queda de trafego > 20%
- ⚠️ Erros de indexacao > 10 paginas
- ⚠️ Core Web Vitals ruim
- ⚠️ Backlinks toxicos
- ⚠️ Acoes manuais no GSC
